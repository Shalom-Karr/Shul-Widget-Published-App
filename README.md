# Shul Widget

Android home-screen widget that shows today's next minyan and shiurim for any Luach-powered shul. Multi-tenant — pick which shul to display when you drop the widget on your home screen.

## Install

1. Grab the latest APK from [Releases](https://github.com/Shalom-Karr/Shul-Widget-Published-App/releases/latest).
2. On your Android phone, open the file and tap install. You may need to allow "Install from unknown sources" the first time.
3. Long-press your home screen → Widgets → drag **Shul Widget** out.
4. Pick your shul.

Supports **Android 7.1.1 (API 25) and up**.

## Features

- Today's next minyan, refreshed automatically
- Daily shiurim
- Zmanim computed on-device (no network round-trip after the first load)
- Auto-updates from this repo's Releases — install once, get every future version automatically
- Works for any Luach shul (CMH, Khal Yereim, Torah Life Kollel, …)
